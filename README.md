# NLP Intelligence Platform

A production-oriented NLP platform for text classification,
sentiment analysis, named entity recognition, semantic search,
and retrieval-augmented generation.

## Goals

- Build reproducible NLP pipelines
- Evaluate model quality
- Provide production APIs
- Measure inference performance
- Implement automated testing
- Implement CI/CD

## Tech Stack

- Python
- PyTorch
- Hugging Face Transformers
- spaCy
- scikit-learn
- FastAPI
- Docker
- GitHub Actions
